# tools/ — обвязка выпуска

Всё, что нужно, чтобы собрать новый выпуск трёх расширений
(`extension/` — компьютер, `extension-android/` — Android, `extension-mobile/` — iPhone),
одной командой и без ручных архивов.

```
node tools/release.mjs check          # проверка деревьев
node tools/release.mjs bump 5.6.2     # версия во всех трёх манифестах
node tools/release.mjs build          # пересобрать builds/
node tools/release.mjs release 5.6.2  # проверка + версия + сборка
```

## Что делает выпуск

1. **Проверка.** Каждый файл, упомянутый в манифесте (фон, контент-скрипты,
   попап, настройки, боковая панель, иконки, включая ссылки внутри
   HTML-страниц), обязан существовать. `src/` всех трёх вариантов обязан быть
   побайтово одинаковым — расхождение считается ошибкой. Именно отсутствие
   этой проверки в 5.6.1 позволило собрать `extension-mobile` без панели,
   настроек и попапа, на которые ссылался его манифест.
2. **Версия.** Пишется в `manifest.json` всех трёх вариантов. Версии обязаны
   совпадать; `package.json` версионится отдельно и на установку не влияет.
3. **Архивы** в `builds/`:
   - `extension-<имя>.zip` — папка `extension/` с расширением + `README.txt`
     и `УСТАНОВКА.txt` из `tools/dist/`; для Android и iPhone рядом лежит
     готовый `.crx` (ставится «из файла», распаковывать не нужно);
   - `extension-<имя>.crx` — CRX₃, подписанный ключом разработчика.
   Имена файлов пишутся в UTF-8 с соответствующим флагом — кириллица больше
   не превращается в `#U0423#U0421…` при распаковке.

## Ключи подписи

Ключ создаётся автоматически при первой сборке варианта и дальше
переиспользуется: `tools/keys/<имя>.pem` (приватный) и `<имя>.json`
(публичный ключ, ID расширения). Каталог в `.gitignore` — в репозиторий
ключи не попадают.

**Важно.** Ключ определяет ID расширения. Пока ключ жив, новые выпуски
обновляются у пользователей незаметно. Потеря ключа = новый ID =
переустановка у всех. Ключи нужно беречь так же, как пароли от ботов.

Ключи, которыми были подписаны выпуски до 5.6.2, не сохранились, поэтому
у сборок 5.6.2 новые ID (они напечатаны в `tools/keys/*.json`):

| вариант | ID |
|---|---|
| desktop | `gccojljmciehbpgfcdmjafbhbemdnckc` |
| android | `mafhcjoffoaapdphjkjgkchkheniphmj` |
| mobile  | `pippkjgphdobklagnckmamaflgcfjamo` |

## Файлы

```
tools/release.mjs   команды выпуска (проверка → версия → сборка)
tools/lib/zip.mjs   ZIP-писатель без зависимостей (детерминированный, UTF-8)
tools/lib/crx.mjs   CRX₃: подпись RSA-PSS/SHA-256 по спецификации Chromium
tools/dist/         README.txt и УСТАНОВКА.txt, кладутся в каждый архив
tools/keys/         ключи разработчика (в git не попадают)
```
