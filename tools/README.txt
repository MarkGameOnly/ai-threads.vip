AI Threads VIP
=============================================

Центр всего — ЧАТ в боковой панели («Спросите ThreadsAI»). Пишешь на русском,
что сделать, — он делает. Работает на твоём ключе AI Threads
(@aithreads50_bot — 50 бесплатных генераций, @aithreadsvip_bot — безлимит).

ГЛАВНОЕ
-------
• 💬 Чат-мозг: понимает команды и сам вызывает инструменты:
    «спарси ленту», «найди клиентов», «разбери автора @nickname»,
    «запусти комментинг», «сгенери пост про X», «запусти охотника».
• 🕵️ Охотник за клиентами (5 шагов):
    1) строит поисковые гипотезы под твой бизнес
    2) собирает выдачу по всем запросам
    3) оставляет свежие уникальные ветки
    4) строгая AI-квалификация → топ лидов
    5) идёт комментировать их, мягко продвигая тебя.
• 🔎 Парсинг с РЕАЛЬНЫМИ метриками: ♥ лайки, 💬 комменты, 🔁 репосты, ✈ шеры
    (не нули). Кол-во постов настраивается (по умолчанию 50, можно больше).
• 📄 Таблица «Посты»: сортировка, фильтр «Только залетевшие», кнопка
    «✍ Переписать под меня» — агент переписывает залетевший пост в твоём стиле.
• 🎯 Клиенты: список лидов со score, причиной и «заходом», кнопка сгенерить коммент.
• 💬 Комментинг: авто / ручной / только-текст. Пресеты промптов уже внутри;
    комменты короткие (1 предложение, ~130–150 символов).
• 📝 Автопост: очередь тем, слоты утро/день/вечер/ночь. Посты из Telegram-бота.
• ✉️ Директ (эксперимент): черновики живых ответов с одобрением перед отправкой.
• ✦ На каждом посте в ленте — кнопка для мгновенной генерации коммента.
• Чёрная тема во всём UI. Уведомления о лидах в Telegram (опц.).

УСТАНОВКА
---------
1. Компьютер: chrome://extensions → «Режим разработчика» →
   «Загрузить распакованное расширение» → выбери папку extension
   (ту, внутри которой лежит manifest.json).
2. iPhone: файл .crx из этого архива ставится через Orion Browser
   (подробно — в УСТАНОВКА.txt из этого же архива).
3. Иконка расширения → войди по Telegram ID и ключу из «Кабинета» бота.
   Можно и одной ссылкой из бота — расширение подхватит её само.

БЫСТРЫЙ СТАРТ
-------------
• В чате: «спарси 80 постов» → вкладка «Посты» (реальные цифры).
• «найди клиентов» → вкладка «Клиенты».
• «разбери автора @nickname» → разбор: взлёты/падения, боли, триггеры,
  структура, время и регулярность.
• Кнопка «🕵️ Охотник за клиентами» → опиши бизнес, «Запустить программу».

ВАЖНО (честно)
--------------
• Threads периодически меняет вёрстку. Метрики читаются по aria-label и по
  числам в панели действий; если где-то нули или кнопка не жмётся — нажми
  «Калибровка» на панели, посмотри отчёт и поправь Настройки → Селекторы.
• Авто-комментинг/постинг эмулируют клики по интерфейсу Threads — это против
  правил автоматизации платформы, риск лимитов/бана. По умолчанию режим
  «черновик» (текст вставляется, отправляешь ты), плюс паузы, дневные лимиты
  и «живой контроль» спорных комментариев через Telegram.
• Программы работают, пока открыта вкладка Threads. На телефоне интерфейс
  живёт в нижней шторке — вкладка не уходит в фон, программы не засыпают.

Структура:
  src/shared/     ai.js, telegram.js, storage.js — общие клиенты, пресеты
  src/background/ service-worker.js — реле, хранилище, планировщик
  src/content/    threads-dom.js (парсер), threads-aim.js (клики/ввод),
                  threads-engine.js (движок), threads-rpc.js (команды),
                  threads-panel.js (кнопки в ленте), sheet.js (шторка)
  src/sidepanel/  panel.* — чат-мозг, инструменты, вкладки
  src/options/    настройки и пресеты
  src/popup/      попап
